# OctaDecathlon Sports Store

A Python and MySQL based Sports Store Management System.

## Features

- Inventory Management
- Add Products
- Delete Products
- Update Products
- Filter Products
- Purchase Tracking
- Order History

## Technologies Used

- Python
- MySQL
- Tabulate

## Database Tables

- Cricket
- Football
- Basketball
- Volleyball
- Motor_Sport
- Order_History

## How to Run

1. Install Python
2. Install MySQL
3. Run database.sql
4. Run sports_store.py
